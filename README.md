# Object-Oriented Programming in C++

This repository contains C++ programs demonstrating key Object-Oriented Programming (OOP) concepts and advanced C++ features. Each file focuses on one concept with clear code examples and in-code comments.

## 🔹 OOP Concepts

- **Classes and Objects**  
  `class_example.cpp` – Demonstrates basic class structure and object instantiation.

- **Inheritance**  
  `inheritance_demo.cpp` – Example of single and multilevel inheritance.

- **Polymorphism**  
  `polymorphism_example.cpp` – Shows both compile-time and runtime polymorphism using function overloading and virtual functions.

- **Encapsulation**  
  `encapsulation.cpp` – Encapsulation using access specifiers (`private`, `public`).

- **Abstraction**  
  `abstraction.cpp` – Use of abstract classes and pure virtual functions.

## 🔸 Advanced C++ Concepts

- **File Handling**  
  `file_handling.cpp` – Demonstrates reading from and writing to text files using `ifstream` and `ofstream`.

- **Templates**  
  `templates.cpp` – Example of function and class templates to achieve generic programming.

- **Exception Handling**  
  `exception_handling.cpp` – Shows use of `try`, `catch`, and `throw` for error handling.
